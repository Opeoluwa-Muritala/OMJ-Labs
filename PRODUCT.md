# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
Recruiters, hiring teams, potential startup collaborators, and others evaluating Opeoluwa Muritala Joel's engineering work.

## Product Purpose
Present Opeoluwa's founder work at OMJ Labs, career experience, and selected projects, helping visitors understand the work and connect through LinkedIn or GitHub.

## Positioning
The portfolio shows Opeoluwa's work across Android, web, backend, and AI-native product development, with curated project context alongside live public GitHub repository metadata.

## Operating Context
Visitors typically scan the first screen, inspect selected projects, then follow source links or contact links. The site is public and works on desktop and phone screens.

## Capabilities and Constraints
- Feature selected work including FieldCRM, SabiMarket, ScholarNavigate, ticket-api, kflite, Event-Response, Haven Check, Songs of the Kingdom, New_Kuz, ShopPal, and Aptus. Keep project pages connected to the portfolio grid.
- New_Kuz replaces OpenChat at the user's request. Its public README documents a real-time Kotlin/Compose messaging app for the KUZ community using Firebase and Room.
- Request public GitHub repository metadata on each visit and retain curated project content when the request fails.
- Do not include a contact form. Use verified LinkedIn and GitHub links, and link to the public résumé PDF supplied by the user.
- The profile README's `ticket-api` URL currently returns 404; show the project without a source link until a matching public repository is confirmed.
- Opeoluwa founded OMJ Labs, an AI-native startup. The Quizz repository documents Aptus, a recruitment and assessment portal. Public live domains are `fieldlms.omjlabs.com`, `aptus.omjlabs.com`, and `shoppals.omjlabs.com`.

## Brand Commitments
Use Opeoluwa's name and a dark editorial visual direction. The chosen redesign is an OMJ Labs studio folio with a personal statement, a graphic portrait area without Opeoluwa's likeness, and a distinct visual treatment for each project. Outside the app cards use deep charcoal, warm ivory, and muted lime only for small highlights and buttons. App cards may use their products' own colors. The layout should fill the browser width; Three.js adds subtle motion to the hero and studio graphics.

## Evidence on Hand
- The public GitHub profile README supplies career details and descriptions of the featured projects.
- Public GitHub repository metadata and verified links supply current project information.
- The public résumé PDF supplies additional professional experience. Its city and expected graduation year conflict with the GitHub profile, so the site will use the broader location "Nigeria" and omit a graduation year.
- The user chose a graphic portrait area without a personal likeness.

## Product Principles
- Show the work clearly before asking visitors to make contact.
- Preserve factual, verifiable career and project content.
- Keep every project understandable even when GitHub data is unavailable.
- Make navigation and reading comfortable on desktop and phones.
